# MiCA Compliance Checklist

## Markets in Crypto-Assets Regulation (EU 2023/1114)

This checklist tracks PrimeCrypto's compliance with MiCA requirements for Crypto-Asset Service Providers (CASPs).

**Full MiCA Enforcement Date**: July 1, 2026

---

## 1. Token Classification ✅

- [x] **Determine token type**: Utility token (not ART or EMT)
- [x] **Document classification rationale**: Token provides platform access, not asset-backed
- [ ] **Legal opinion**: Obtain from qualified EU crypto counsel

### Classification Evidence

| Criterion | Status | Notes |
|-----------|--------|-------|
| Provides platform utility | ✅ | Access to agent marketplace, governance |
| Not backed by assets | ✅ | No reserve requirement |
| Not a means of payment | ✅ | Primary use is ecosystem participation |
| Not a security | ✅ | No profit expectation from others' efforts |

## 3. Crypto-Asset Service Provider (CASP) Authorization

### Pre-Authorization

- [ ] **Select EU jurisdiction**: France (AMF) recommended
- [ ] **Engage legal counsel**: Crypto-specialized EU lawyer
- [ ] **Prepare application**: Corporate documents, business plan
- [ ] **Submit application**: Timeline 3-6 months

### Authorization Requirements (Article 59)

- [ ] **Legal entity in EU**: Register company in France
- [ ] **Registered office**: Physical presence in EU
- [ ] **Management fit & proper**: Background checks passed
- [ ] **Capital requirements**: €50,000 - €150,000 minimum
- [ ] **Business continuity**: Documented procedures
- [ ] **Governance arrangements**: Board, compliance function

### Services Requiring Authorization

| Service | Required | Status |
|---------|----------|--------|
| Custody | ❌ | Self-custody only |
| Exchange | ❌ | DEX only (decentralized) |
| Order execution | ❌ | Automated via smart contracts |
| Transfer services | ✅ | If operating bridge/relay |
| Advice | ❌ | Not providing investment advice |

## 5. Anti-Money Laundering (AML) / KYC

### Customer Due Diligence (CDD)

- [ ] **KYC procedure**: Identity verification for users
- [ ] **Risk-based approach**: Higher scrutiny for large transactions
- [ ] **Ongoing monitoring**: Transaction screening
- [ ] **PEP screening**: Politically exposed persons check

### Travel Rule Compliance

- [ ] **Transfer of funds**: Include originator/beneficiary info
- [ ] **Threshold**: €1,000+ requires full data
- [ ] **Technical solution**: Implement transfer messaging

### Record Keeping

- [ ] **5-year retention**: Transaction and customer data
- [ ] **Secure storage**: Encrypted, access-controlled
- [ ] **Audit trail**: All decisions documented

### Suspicious Activity

- [ ] **SAR procedure**: Suspicious Activity Report process
- [ ] **Reporting timeline**: <24 hours to FIU
- [ ] **Staff training**: AML awareness program
